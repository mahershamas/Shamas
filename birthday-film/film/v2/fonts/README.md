# Fonts

`cormorant-lf-roman.woff2` and `cormorant-lf-italic.woff2` are modified versions of Cormorant Garamond
(Copyright 2015 The Cormorant Project Authors, https://github.com/CatharsisFonts/Cormorant), licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org). The only modification remaps the digits to the font's own
lining figures, because Canvas2D cannot enable OpenType features. They remain under the SIL OFL 1.1.
